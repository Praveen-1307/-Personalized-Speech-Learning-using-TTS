# Quick Review: SWE Interview Cheat Sheet

*   **Code Analysis:** Understanding inputs, logic, tradeoffs, and performance limits without memorizing syntax.
*   **Building Blocks:** Modular parts of a system (Input $\rightarrow$ Extractor $\rightarrow$ AI Engine $\rightarrow$ Output) that connect like Legos.
*   **Memory vs Storage:** Memory (RAM) is the temporary fast desk; Storage (SSD/HDD) is the permanent slow filing cabinet.
*   **RAM Functionality:** Holds active apps. Running massive AI models spikes RAM, risking "Out of Memory" crashes.
*   **1 GB Bytes:** Base-10 (Hard drives) = 1 Billion. Base-2 (Windows/RAM) = 1,073,741,824.
*   **PC vs Mobile Storage:** PC is massive and upgradable (SSD). Mobile is tiny, low-power, and soldered (non-upgradable).
*   **Tech Vocab & Observation:** Using precise engineering terms and finding bug patterns in error logs (like a detective).
*   **Articulation:** The vital ability to translate complex tech into simple business terms for teammates and bosses.
*   **SWE Skills in AI Era:** Code reviewing, system architecture, prompt engineering, and deep debugging.
*   **Feynman Technique:** The test of true knowledge: If you can't explain it simply to a 12-year-old, you don't understand it.
*   **Fluid Intelligence:** Using raw logic to solve brand new, unseen problems instead of relying on memorized answers.
